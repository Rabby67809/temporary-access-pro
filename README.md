# Temporary Access Pro

Secure, scoped and time-limited WordPress access with live session control.

## Current foundation
- Versioned plugin bootstrap
- Database migration layer
- Tasks, grants, sessions and audit events schema
- REST heartbeat foundation
- Least-privilege capability model
- Planned GitHub release/update workflow

## Product direction
A premium Live Control Center for temporary workers, agencies, contractors and support teams.

Monitoring is limited to WordPress/plugin actions and session state; no keylogging, screen recording, camera/microphone capture, or unrelated tab/app surveillance.
